# MacBook Management

MacBook 구성과 관리에 관한 개인 원칙을 기록하는 저장소다. 설치 방법, 디렉토리 배치, 개발환경, shell, Git과 SSH, 복구에 관한 판단 기준을 장기간 관리한다.

이 저장소는 원칙을 설명하는 문서만 관리한다. 현재 머신의 설치 상태, 개인 계정 정보, 기기 고유 값은 관리하지 않는다.

## 적용 기준

- 운영체제: macOS
- architecture: Apple Silicon
- 기본 shell: `/bin/zsh`
- Homebrew prefix: `/opt/homebrew`
- GitHub 접근 방식: SSH

이 값은 문서가 전제로 삼는 관리 기준이다. 저장소가 현재 머신을 자동으로 검사하거나 변경한다는 뜻은 아니다.

적용 기준을 바꿀 때는 각 원칙 문서의 `기본 환경` 표와 재설치 절차에서 같은 전제를 사용하는 부분을 함께 검토한다.

## 문서 관리 원칙

- 하나의 사실에 관한 기준은 한 문서에서만 관리한다. 다른 문서에서는 기준을 소유한 문서로 링크한다.
- 상세한 문서 표기·용어·구조 규칙은 [AGENTS.md](AGENTS.md)에서 관리한다.
- 설정이나 선택을 기록할 때는 이유, 적용 위치, 검증 방법, 제거 방법을 함께 설명한다.
- macOS나 도구의 version에 따라 바뀔 수 있는 명령은 공식 문서를 다시 확인하도록 명시한다.
- 기존 문서와 다른 책임이 생길 때만 새 파일을 추가한다.

## 변경 흐름

1. 기존 원칙과 충돌하거나 중복되는지 확인한다.
2. 선택의 이유와 대안을 정리한다.
3. 책임이 가장 가까운 문서 한 곳을 수정한다.
4. 관련 문서의 링크와 표현을 함께 검토한다.
5. secret 또는 머신 고유 정보가 포함되지 않았는지 확인한다.

## 현재 범위 밖의 항목

- 현재 머신의 설치 애플리케이션 및 CLI 목록: 이 저장소는 원칙만 관리하고 머신의 현재 상태는 관리하지 않는다.
- 실제 dotfiles 원본과 머신별 override: 문서는 배치와 책임만 설명하고 실제 설정 파일은 관리하지 않는다.
- password, token, SSH key, 인증서 private key: 개인 계정 정보와 secret은 관리 대상이 아니다.
- package 설치·삭제 또는 시스템 설정을 실행하는 자동화: 저장소가 현재 머신을 자동으로 변경하지 않는다.
- 자동으로 `$HOME`에 설정 파일을 배포하는 bootstrap 기능: 먼저 수동 절차와 안전 조건을 문서화하고 반복 필요가 확인될 때 별도 책임으로 검토한다.

설정 예시나 script를 반복해서 사용할 필요가 생길 때만 별도 디렉토리를 추가한다. 먼저 수동 절차와 안전 조건을 문서화한다.
